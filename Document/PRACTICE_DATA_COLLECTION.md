# 练习数据收集与导出说明（PRACTICE_DATA_COLLECTION）

> 本文是面向使用者的简明说明，描述 WindScore 的两类练习数据流：**本地自动私密记录**与**由用户主导的收集/导出**。
> 文末验收清单列出需要真实设备手工执行的检查；**本文不声称这些硬件/手工检查已完成**。

## 1. 两类数据流

| | 本地自动私密记录 | 收集与导出 |
|---|---|---|
| 触发 | 打开乐谱并连接 MIDI 后练习时自动进行 | 用户在“练习记录收集与导出”页手动选择、预览并保存 |
| 存放 | 仅本机应用私有存储（`attempts/<scoreId>/` 下的 CBOR 文件），不自动上传 | 通过系统原生对话框手动选择目标位置，保存一份 JSON 文件 |
| 内容 | 演奏的原始按键事件（NoteOn/NoteOff）＋练习条件与边界证据 | 经白名单过滤的摘要；原始事件仅在显式勾选后包含 |
| 用途 | 本机留存与诊断 | 需要分享或分析时，由用户审查预览后手动导出 |

应用没有任何上传、遥测或联网导出路径；离开本机的唯一方式是用户手动保存并自行分发文件。

## 2. 本地自动私密记录如何工作

- 记录只来自你在 MIDI 键盘上的真实按键。自动代奏（hosted 手）的合成音、播放（playback）都不会进入记录。
- 一次“尝试（attempt）”在以下情况自动切分：重新开始、单手/视图/循环条件变化、进入或退出评分、MIDI 禁用或断开、离开乐谱页面、应用中断。
- 结束原因枚举：`COMPLETED` / `USER_STOPPED` / `USER_RESTARTED` / `NAVIGATED_AWAY` / `MIDI_DISCONNECTED` / `APP_INTERRUPTED` / `FREE_PLAY_MARKED`。
- `COMPLETED` 表示“剩余应弹的起音组已弹完”。从中间恢复或起点位于区域内部，并不代表完整走过整个区域，也不代表计时准确；立即完成不包含随后的松键（NoteOff）尾巴，数据质量标志会提示这一点。
- 时长包含从武装（arming）开始的准备/等待时间。
- 速度为 0 时托管推进与声音暂停，不会产生虚假完成；恢复正速后继续。实际速度反映在 `requestedTempo` / `effectiveHostedTempo`（0 速时为空）。评分会话始终使用基础速度 1。
- 播放期间练习判定与托管暂停，播放不会被当作演奏；播放结束后满足条件才重新武装记录。
- MIDI 禁用或断开会结束当前尝试；断开不会再凭记忆自动开新尝试；重新启用只武装“当前”符合条件的会话。
- 保存是异步且独立的：页面导航不会取消已定稿的写入。强制杀死进程仍可能丢失进行中的缓冲。

## 3. 收集与导出页（评分设置面板入口）

- 初始状态：列表加载后**一条都不选**，“包含原始 MIDI 事件”**默认不勾选**。
- 没有已保存记录时显示空状态；读取失败会明确报错，不会把失败伪装成空数据。
- 勾选后实时生成“导出预览”；**预览内容与写盘字节完全一致**（同一次序列化的同一份字节）。
- 保存：点击“保存 JSON…”，在系统对话框中选择位置，默认文件名 `windscore-practice-collection.json`（可改名）。
- 保存期间（Desktop 与 Android 一致）：尝试选择、选项、返回均被锁定；`关闭乐谱`、设置弹窗关闭、内容返回被阻止；Desktop 主窗口关闭被阻止且标题栏显示本地化的“正在保存…”；Android 系统返回被阻止并提示。
- 结果只有三种并明确显示：**已保存** / **已取消（没有导出文件）** / **保存失败（请检查所选位置是否可写）**。取消、失败、写入被取消都会释放界面锁定，可再次保存。
- 写盘的字节在打开系统选择器**之前**捕获；之后即使修改选择，保存的仍是点击保存那一刻的快照。
- 界面锁定无法阻止系统级事件：强制杀进程、系统或外部提供方故障仍可能中断写入。

## 4. 敏感性与“别名不等于匿名”

- 摘要导出不含音符列表、乐谱标题/ID/哈希/路径、设备身份、真实时间戳，也不含本地记录/会话 ID；只含相对位置、练习条件、事件计数与中性数据质量标志。
- 但乐谱位置、练习条件与音乐规律本身仍可能敏感，足以识别曲目或演奏者。
- 勾选原始 MIDI 后，导出包含音高/力度/相对时间，敏感度显著更高，可能泄露曲目、音符与演奏特征；大量原始事件也会产生较大的 JSON。
- `score-1` / `session-1` / `attempt-1` 等别名只是稳定的假名（pseudonyms），**降低直接识别，不保证匿名**。请自行决定是否以及如何分享。

## 5. 乐谱别名 / 版本 / divisions

- `scoreAlias`：按本次所选乐谱的确定顺序生成（score-1、score-2…），与勾选点击顺序无关；同一选择下别名永远稳定。
- `sessionAlias`：以（乐谱， 会话）为作用域；不同乐谱即使共享内部会话 ID 也不会被合并。
- `attemptAlias`：按确定性顺序编号（attempt-1、attempt-2…）。
- `scoreVersion`：乐谱版本号。`divisions`：可为空（旧记录没有该字段时）。

## 6. 文件与字段解读

- 信封：`format=windscore-practice-collection`，`schemaVersion=1`，`appVersion`（Desktop `1.0.0`，Android `1.0`），`sourceRecordingSchemas`（各记录的录制格式版本），`containsRawMidi`，`attempts[]`。
- 时间与位置均为相对量：`offsetMicros` 相对尝试开始、单调不减（允许相等）；tick 位置以所选区域起点为 0。
- 原始事件字段：`type` / `pitch` / `velocity` / `offsetMicros` / `sessionOffsetTicks` / `sessionGroup`。其中 `sessionOffsetTicks`、`sessionGroup` 是等待引擎在按键时刻的位置证据，**不是**对齐时间或演奏时长，请勿据此推断音符时值。
- 数据质量标志（`dataQuality`）：
  - `boundary_may_exclude_later_releases`：立即完成后的松键可能落在边界外，勿推断音符长度；
  - `keys_were_held_at_attempt_start` / `keys_were_held_at_attempt_end`：边界处有持续按住的键；
  - `unmatched_release_events_observed`：存在无对应按下的事件；
  - `attempt_started_inside_selected_region`：起点在所选区域内部；
  - `duration_unknown` / `no_midi_events_recorded`：旧数据无时长 / 该尝试无事件。
- 收集页列表中的“本地记录 …尾号 / 会话 …尾号”仅用于本地诊断定位，**不会**出现在导出文件里。
- 导出不打包音频或乐谱源文件，只有这一份 JSON。

## 7. 10–20 次真实尝试验收清单（需手工执行；本文不声称已完成）

用一条有代表性的乐谱，共完成 10–20 次普通尝试覆盖以下场景；每项都核对收集页列表与导出 JSON 的字段一致性：

1. [ ] 双手模式：完成若干尝试，出现 `COMPLETED` 行，时长/到达位置合理。
2. [ ] 单手模式（右手、左手各验一次）：条件切换处自动切分；代奏手的音不出现在记录/原始事件中。
3. [ ] 完整弹完所选区域：结束原因为 `COMPLETED`，completed/boundary 位置接近区域终点。
4. [ ] 单组循环：设单组循环并多次通过，记录包含多个循环通过且顺序正确。
5. [ ] 收尾循环（循环结束于乐谱结尾）：最后一次通过正确标记完成。
6. [ ] 速度 0：托管推进暂停、无虚假完成；恢复正速后继续正常记录。
7. [ ] 速度改变：改变后 `requestedTempo` / `effectiveHostedTempo` 反映实际速度。
8. [ ] 重新开始（reset）：出现 `USER_RESTARTED` 切分，证据不跨尝试串扰。
9. [ ] Seek/步进：中途跳转后出现相应边界证据与 `attempt_started_inside_selected_region` 等标志。
10. [ ] 播放排除：播放期间不新增尝试/事件；停止播放后恢复武装。
11. [ ] MIDI 禁用：当前尝试结束；重新启用后新尝试属于当前会话。
12. [ ] MIDI 断开与重开：断开以 `MIDI_DISCONNECTED` 结束；重开仅在当前会话符合条件时武装。
13. [ ] 取消保存：系统对话框点取消 → 显示“已取消保存；没有导出文件”，磁盘无新文件。
14. [ ] 保存失败：选择不可写位置 → 显示保存失败，应用不崩溃、可再次保存。
15. [ ] Desktop 选择器/覆盖：默认文件名正确；对已存在文件执行覆盖并核对文件内容。
16. [ ] Android SAF：系统文档创建器可用；注意所选提供方可能是远程（如云）位置，应用无法保证目标在本地。
17. [ ] 保存期间返回/关闭：各平台所有返回与关闭路径被阻止；保存完成后界面恢复可用。
18. [ ] 数据字段一致性：导出文件字节与预览一致；`eventCount` / `noteOnCount` / `noteOffCount` 与列表一致；别名稳定；无乐谱标题/ID/设备/真实时间戳泄漏。
